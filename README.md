# 🍳 KitArtChef Studio (Reels Maker)

Локальная веб-студия для автоматизированного монтажа вертикальных кулинарных роликов (Reels, Shorts, TikTok) для блога **@KitArtChef**. Приложение объединяет генерацию голоса, динамичный видеомонтаж, синхронизацию субтитров и экспорт готового контент-пака в едином веб-интерфейсе.

---

## ⚡ Ключевые возможности

* **Гибридный 5-сценный монтаж:**
  * **Сцена 1:** поддержка живого видеохука (Google Flow / MP4) или статичного макро-фото.
  * **Сцены 2–5:** автоматический кинематографичный зум (Ken Burns effect) для предметных фото блюда.
* **Синтез речи (Edge-TTS):**
  * Профессиональный закадровый голос Дмитрия (`ru-RU-DmitryNeural`).
  * Точный тайминг озвучки под каждую сцену с защитой от сбоев сети.
* **Синхронные субтитры:**
  * Посекундная привязка текста к смене планов.
  * Трендовое оформление с обводкой и контрастной подложкой, адаптированное под безопасные зоны мобильных приложений.
* **Управление скоростью готового видео:**
  * Интерактивный ползунок предпросмотра скорости в браузере (`0.75x` — `1.75x`).
  * Быстрый перерендер через FFmpeg с фильтром `atempo` (сохраняет естественную высоту голоса без писка и искажений).
* **Генератор Post Kit:**
  * Автоматическое создание сопроводительного текста к ролику: заголовок, граммовки, КБЖУ и целевые кулинарные теги.

---

## 🛠 Стек технологий

* **Backend:** Python 3.10+, Flask
* **Обработка медиа:** MoviePy, FFmpeg, Pillow
* **Синтез речи:** `edge-tts`
* **Frontend:** HTML5, CSS3 (темная тема), чистый JavaScript (модульная архитектура)

## 🚀 Быстрый старт

### 1. Требования к окружению
* Установленный **Python 3.10** или выше.
* Установленный в системе **FFmpeg** (утилита должна быть добавлена в системные переменные `PATH`).

### 2. Установка
Клонируйте репозиторий и перейдите в папку проекта:
```bash
git clone [https://github.com/mezhig59ru/kitartchef-studio.git](https://github.com/mezhig59ru/kitartchef-studio.git)
cd kitartchef-studio

Установите зависимости:
pip install flask moviepy edge-tts pillow requests

Запустите сервер:
python app.py

Откройте веб-интерфейс в браузере по адресу:
[http://127.0.0.1:5000](http://127.0.0.1:5000)
